Before Pip can see you — your consent

Pip is a small toy with a camera for a heart. Please read this first — nothing is captured until you agree:

  • What happens: if you choose live mode, your webcam turns on and the Presage SmartSpectra SDK measures your pulse, breathing, and facial expressions from the video, on this machine, in real time.
  • Recorded check-in: instead of a live camera, Pip can replay a short face video recorded earlier and measure that file with the same SDK, on this machine. The page labels it RECORDED CHECK-IN REPLAY the whole time — a replay is never presented as live.
  • Nothing is kept: Pip does not record video, does not take screenshots, and does not store your measurements. Close the tab or press Stop and everything is gone — there is nothing to delete later.
  • Where frames go: frames are processed in memory by the SDK on this computer. The SDK talks to Presage only to authenticate the API key. Pip's own server (also on this computer) adds no uploads of its own.
  • SDK telemetry: checking the server setting…
  • Not a medical device: Pip is for play and gentle self-awareness. It makes no diagnosis, gives no treatment advice, and its numbers are estimates for fun — never health decisions.
  • Your choice, always: you can stop at any moment. No covert anything — the camera is only ever on while this page says it is.

Recorded check-in is not available on this server right now — it needs a check-in video file beside the server and the same free API key as live mode (see the README).
